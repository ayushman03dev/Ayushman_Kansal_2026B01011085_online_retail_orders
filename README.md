Online Retail Orders: Data Cleaning using Python
Introduction
Raw business data often has missing values, duplicates, inconsistent text and calculation errors, which can lead to wrong analysis. Data cleaning fixes these problems so the data is accurate and ready to use.
This project cleans an online retail dataset of 10,000 orders (January 2024 to December 2025) using Python, pandas and numpy. The program checks the data, fixes formats and text, handles missing values and duplicates, removes impossible values, verifies revenue, flags outliers and adds new columns for analysis. The cleaned data is saved as a new CSV file.
Things Used
Python 3: programming language
pandas: loading and cleaning the data
numpy: calculations and outlier detection
Google Colab: platform to write and run the code
Dataset: online_retail_orders_10000.csv
Things Required
A Google account and a web browser
An internet connection (Colab needs no installation)
The dataset and the notebook file clean_retail_data_colab.ipynb
Basic knowledge of Python
